CASE STUDY 03

How I redesigned The Hackett Group's finance dashboard to help senior executives compare 15,000+ metrics efficiently and make data-driven strategic decisions


Role

UX/UI Designer

Team

10 members (PM, Developers, Data Team)

Impact

60% Reduction in Time to Insight, 15,000+ Metrics made accessible, 4x Faster Metric switching and comparison workflow

Tools

Figma, InVision, Microsoft Clarity, Whimsical, Lucidchart

About The Hackett Group

The Hackett Group is an enterprise benchmarking platform that measures performance excellence, accelerates business transformation, and uncovers breakthrough business insights for Fortune 500 companies. The platform processes over 15,000 financial and operational metrics to help organizations compare their performance against industry peers and best-in-class performers.

The Problem

Business Challenge

Senior finance executives were drowning in data but starving for insights. Despite having access to comprehensive benchmarking data across 15,000+ metrics, users couldn't efficiently compare performance indicators, switch between metric panels, or identify actionable insights within reasonable timeframes.

Key Issues Identified:

  • No efficient way to compare multiple metrics simultaneously
  • Slow navigation between different metric panels disrupted analysis flow
  • Senior team members lacked time to explore complex interfaces
  • Data overload prevented users from identifying strategic opportunities
  • No clear visual hierarchy to prioritize critical performance indicators

Research & Discovery

Working within an agile environment for The Hackett Group client, I conducted comprehensive user research to understand the complex needs of finance executives and data collectors.

Empathize Phase

Conducted stakeholder interviews with CTO and CEO, followed by extensive user interviews with finance team members and data collectors to understand their workflows, pain points, and time constraints.

Collaborative research and stakeholder interviews with The Hackett Group finance teams.

Key Insights from Research

The platform needed to solve several important challenges. First, Time-Constrained Users like senior finance team members needed fast access to important information without complicated navigation. Second, there was a Comparative Analysis Need because users had to compare many metrics at the same time to make strategic decisions. Also, the system had Complex User Roles (like Program Managers and Data Collectors), which required different levels of access and functionality. Finally, the platform needed to fix the Missing Context of raw metrics and help users focus on the Excellence Quadrant metrics.


The Design Process

Define Phase

Created user journeys and user flows mapping core functionalities. Developed user personas for different roles (Data Collectors, Finance Managers, Executives) to understand how each would complete tasks and what information they needed along the way.

User journey mapping core functionalities and roles within The Hackett Group platform.

Ideate & Prototype

Facilitated collaborative sessions with the 10-member team using Whimsical boards to create flowcharts and user stories. Rapidly iterated on concepts through sketching, wireframing, and functional mockups in Figma.

Multi-Panel Comparison Dashboard

Users needed to compare multiple metrics simultaneously but the existing interface only allowed viewing one metric panel at a time.

Designed a flexible grid-based dashboard that allowed users to display multiple metric panels side-by-side. Implemented quick-switch functionality enabling users to toggle between different metric views without losing context or position.

Grid-Based Layout

Flexible panel system allowing 2-4 metrics displayed simultaneously for direct comparison

Quick-Switch Navigation

One-click metric switching without page reloads or lost context

Customizable Views

Users could save and recall preferred metric combinations for recurring analysis

Visual Data Hierarchy & Excellence Indicators

With 15,000+ metrics, users struggled to identify which data points were most critical for strategic decisions.

Implemented a clear visual hierarchy using color-coding and excellence indicators. Designed a scoring system that highlighted metrics contributing to the "excellence quadrant"—helping users focus on high-impact performance areas.

  • Color-coded performance tiers (Excellent, Good, Average, Below Average)
  • Excellence quadrant badges highlighting top-performing metrics
  • Comparative advantage indicators showing where organizations excel vs. peers
  • Trend arrows and sparklines for quick pattern recognition

Design system and visual hierarchy for The Hackett Group benchmarking dashboard.

Contextual Benchmarking Display

Raw metrics without peer comparison context provided limited actionable insight.

Integrated industry benchmarking directly into each metric panel, showing where the organization stood relative to peers, industry averages, and best-in-class performers.

Guided Onboarding & Presentation Mode

During development, we realized new users needed guidance to understand the platform's extensive capabilities.

Designed a comprehensive onboarding tour and added a presentation mode feature (my suggestion, approved after team discussion). This allowed users to create slide-based reports directly from dashboard data for executive presentations.


Test & Iterate

Conducted A/B testing and usability studies throughout development. Used dynamic mockups in consecutive client meetings to explain, discuss, test, and rethink design decisions. Ensured deliverables matched client needs within the proposed timeframe.

Heatmap analysis from Microsoft Clarity showing user interaction patterns on the dashboard.

15,000+

Qualitative Improvements

  • Enhanced decision-making speed: Executives could now identify strategic opportunities in real-time during meetings
  • Improved data democratization: Multiple user roles could access relevant information without overwhelming complexity
  • Excellence quadrant visibility: Clear visual indicators helped organizations focus on high-impact performance areas
  • Presentation capabilities: Built-in slide generation eliminated manual report creation, saving hours per analysis
  • Scalable design system: Flexible component architecture allowed easy addition of new metric types

Final benchmarking dashboard featuring multi-panel comparison and excellence indicators.

Reflection

Reflecting on this project, I see it offered unique challenges in designing a large, data-intensive platform with many different user needs. My main lesson was that Context is king in data visualization; raw numbers are not helpful unless you can compare them with benchmarks. Also, because of the diverse user roles from Data Collectors to Executives, we needed a very flexible architecture to give everyone the right information. Working with the team in Figma allowed for quick and collaborative iteration, which greatly helped us to reduce mistakes. Finally, the Agile methodology was key, allowing us to adapt the timeline when we discovered high-value features were needed.
